# Windows AirPlay receiver build

The receiver is UxPlay 1.74's experimental Windows implementation, pinned to
`3dbf7ceee65932154e85a2f83963d53520a799fa`. The complete upstream archive and every
local native change are in `../receiver/source/`. UxPlay and this patch are
GPL-3.0-or-later; see `../receiver/LICENSE-UxPlay`.

The shipped receiver was built with MSYS2 UCRT64 GCC 16.2.0, CMake 4.4.4,
GStreamer 1.28.7, libplist 2.7.0 and OpenSSL 3.6.5. `toolchain-packages.txt` records
the actual build environment. A newly updated MSYS2 installation may resolve
different library versions and produce different hashes.

The portable bundle includes the pinned archive. In a source-only checkout, first
run `receiver-build/get-source.ps1` to obtain and verify it. The tracked native
patch is `island-windows.patch`.

In a configured MSYS2 UCRT64 environment, install the build dependencies:

```bash
pacman -S --needed patch mingw-w64-ucrt-x86_64-gcc mingw-w64-ucrt-x86_64-cmake \
  mingw-w64-ucrt-x86_64-ninja mingw-w64-ucrt-x86_64-pkgconf \
  mingw-w64-ucrt-x86_64-libplist mingw-w64-ucrt-x86_64-openssl \
  mingw-w64-ucrt-x86_64-gstreamer mingw-w64-ucrt-x86_64-gst-plugins-base \
  mingw-w64-ucrt-x86_64-gst-plugins-good mingw-w64-ucrt-x86_64-gst-plugins-bad \
  mingw-w64-ucrt-x86_64-gst-libav mingw-w64-ucrt-x86_64-glib-networking
bash /c/path/island-windows/receiver-build/build.sh /c/path/airplay-build
```

`build.sh` extracts into the dedicated workspace, applies the bundled patch,
disables CPU-specific `-march=native`, and enables internal mDNS. An existing source
directory is retained; a different patch requires a fresh workspace. Bonjour is
not a dependency.

From Windows Python, with the receiver stopped, package the result:

```powershell
python .\receiver-build\package-runtime.py `
  --prefix C:\msys64\ucrt64 `
  --build C:\path\airplay-build\build-ucrt64 `
  --source C:\path\airplay-build\UxPlay-3dbf7ceee65932154e85a2f83963d53520a799fa `
  --archive .\receiver\source\uxplay-3dbf7ce-source.zip `
  --output .\receiver
```

The packager follows PE imports from the receiver, scanner, GIO TLS module and
35 required GStreamer plugins. It rejects unresolved non-system imports, includes
the package licenses and CA bundle, and generates a file/hash manifest. The GIO
module cache is generated by `gio-querymodules.exe`; Windows CRLF cache entries
must not be handwritten, because they can silently disable HTTPS support.

The WPF app supplies explicit plugin, schema, scanner, certificate and cache paths.
It uses D3D11 for video, WASAPI for audio, playbin2 for the Linux-compatible HLS
path, and a 5-second default video buffer. Native commands are limited to media
play/pause/seek, fullscreen/aspect ratio, buffer duration and graceful shutdown.
