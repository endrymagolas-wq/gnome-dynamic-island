# Changelog

## 0.1.0-beta.1

First public GNOME 46 beta. Native media island and artwork, smart top-edge reveal, 0.3-second track controls, phone/system volume feedback, Ink quick settings, compatible titlebar traffic lights, per-app mixer and focus tools. Optional offline Laya monitor includes conservative notifications, history, category mute, resource diagnosis, idle unload and persistent full OFF. User-local install/restore and clean source archive; no runtime data or model weights bundled.
